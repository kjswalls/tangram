# Data sources and licences

Tangram's dictionary is generated by `pnpm data` (`scripts/build-data.ts`) from the four
sources below into three artifacts: `data/dict-<schema>-<snapshot>.sqlite` (the dictionary
the app queries), `data/dict.json` (the same rows as JSON, the build's intermediate and the
verifier's oracle) and `data/decomp.json`. None of the three is committed; this file and
`COPYING-makemeahanzi` are, and both are shown in `/settings`.

The **typefaces** are a separate obligation from the data and have their own section at the
end of this file. Since `web.md` W6 the web build self-hosts `unicode-range`-split subsets
of four OFL families, and subsetting makes each of them a Modified Version under that
licence — so the licence has to travel with the bytes, which means it is reproduced here
rather than only in the repository.

`decomp.json` is kept a separate file because its licence differs: it is LGPL, it is never
merged into the SQLite dictionary, and it never travels inside a card snapshot or a model
prompt. `scripts/verify-data.ts` asserts that separation against the built artifact rather
than leaving it to convention.

## CC-CEDICT — headwords, pinyin, glosses

- Source: the [`cedict-json`](https://www.npmjs.com/package/cedict-json) npm package, a
  JSON rendering of [CC-CEDICT](https://cc-cedict.org/); the exact snapshot version is
  recorded in `meta.version` inside `data/dict.json`.
- Copyright © the CC-CEDICT contributors (MDBG).
- Licence: **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)** —
  <https://creativecommons.org/licenses/by-sa/4.0/>

**Modification notice.** Tangram's `data/dict.json` and the
`data/dict-<schema>-<snapshot>.sqlite` built from it are modified versions of CC-CEDICT:

- Tone-marked pinyin (`pinyinMarked`, e.g. `dǎsuàn`) is derived mechanically from
  CC-CEDICT's numbered pinyin (`da3 suan4`) by `lib/dict/pinyin.ts`. No reading is edited,
  added or removed. Syllables are joined the way pinyin orthography writes a word, with a
  space where CC-CEDICT's capitalisation marks a new word of a name (`Shao4 lin2 Si4` →
  `Shàolín Sì`); `xx5`, CC-CEDICT's marker for a headword it has no Mandarin reading for,
  renders as the empty string rather than as the letters `xx`.
- `CL:` classifier references are lifted out of the gloss list into a `classifiers[]`
  field — both the standalone `CL:…` lines and the `(CL:…)` suffixes CC-CEDICT appends to
  a sense. The information is unchanged; only its place in the record moved.
- Each entry is annotated with fields from the other sources below (`hskBand`, `pos`,
  `freq`, `freqRank`) and with flags derived from the glosses themselves (`isVariant`,
  `properNoun`, `surname`, `variantOf`).
- The SQLite artifact adds no dictionary content. It reindexes the same rows: two pinyin
  lookup keys derived mechanically from the numbered pinyin, an English gloss index over
  stemmed gloss tokens, a headword-frequency table for word segmentation, and a
  character-to-headword index. Every gloss is stored exactly as `dict.json` has it.
- The rows are stored in a derived order, not CC-CEDICT's: by `freq`, then real words
  before variants before proper nouns, then `hskBand`, then entry id. That order decides
  which reading of a headword the app shows first (看 as kàn before kān); no reading is
  removed by it.

Definitions are otherwise reproduced verbatim, and the derived file is offered under the
same CC BY-SA 4.0 licence. AI-written prose in the app is the model's own expression about
attributed entries; the answer cache stores entry ids and sense indexes, never gloss text.

## Make Me a Hanzi — character decomposition (`data/decomp.json`)

- Source: <https://github.com/skishore/makemeahanzi> (`dictionary.txt`), itself derived
  from [Unihan](https://unicode.org/charts/unihan.html) and
  [CJKlib](https://github.com/cburgmer/cjklib).
- Licence: **GNU Lesser General Public License, version 3 or later
  (LGPL-3.0-or-later)** — <https://www.gnu.org/licenses/lgpl-3.0.html>. The upstream
  notice is committed verbatim beside this file as `COPYING-makemeahanzi`.
- Tangram uses only `decomposition`, `radical` and `definition`, reshaped into a
  character-keyed JSON object. The project's stroke graphics (`graphics.txt`, the SVGs)
  are under the Arphic Public License and are **not** used.
- **None of it reaches the SQLite dictionary.** Make Me a Hanzi is deliberately absent from
  that file's own `meta.sources`, because the file derives nothing from it;
  `scripts/verify-data.ts` and `tests/unit/dict/artifact.test.ts` both check that no
  decomposition data is in it.

## Typefaces — the fonts the app ships (`apps/app/src/fonts/*.woff2`)

Not a data source: these are shipped software. `pnpm font:subset` cuts them from the
binaries `pnpm font:fetch` vendors, and the app serves them from its own origin rather than
from a font CDN (`docs/plans/web.md` W6).

- Licence: **SIL Open Font License, Version 1.1**, for all four families. The text is
  reproduced in full below, because OFL clause 2 requires each copy of the Font Software to
  carry the copyright notice and this licence — and these copies are the ones every visitor
  downloads.
- **Every shipped file is a Modified Version.** Each `.woff2` is a subset of its source, cut
  to the code points its `unicode-range` claims so that a page downloads only the blocks it
  renders. Nothing else is changed: the glyph outlines, the variable weight axis and the
  `name` table — including each family's copyright string — are the upstream ones.
- **No Reserved Font Name is used by a modified version.** DM Sans, Newsreader and Noto
  Serif SC declare none at all. Noto Sans SC's is `Source`, and `Source` appears in none of
  the shipped subsets' family, full or PostScript names.

The four families, their copyright holders and what each one draws:

- **Noto Serif SC** — © 2017–2024 Adobe (<http://www.adobe.com/>), from Google's build of
  the family, © 2012 Google Inc. It is `--font-hanzi`: every Chinese character in the app.
- **DM Sans** — © 2014 The DM Sans Project Authors
  (<https://github.com/googlefonts/dm-fonts>). It is `--font-ui`: the interface, and marked
  pinyin.
- **Newsreader** — © 2020 The Newsreader Project Authors
  (<http://github.com/productiontype/Newsreader>). It is `--font-display`.
- **Noto Sans SC** — © 2014–2021 Adobe (<http://www.adobe.com/>), with Reserved Font Name
  'Source'. Nine glyphs only: the pinyin tone vowels U+01CD–U+01DC, which DM Sans and
  Newsreader have no glyph for and which are every third tone in Mandarin.

Upstream is Google Fonts' own build of each family, from `google/fonts`. The exact bytes are
pinned by sha256 in `scripts/fonts.ts`, and `pnpm font:fetch` refuses a file whose digest
has moved.
